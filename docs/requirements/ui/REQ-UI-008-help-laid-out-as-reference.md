## Statement

The help dialog **shall** be laid out as a reference: up to 860 px wide with
paragraphs limited to a readable measure (76 characters), and sections for
reading the map, for walk mode, for each kind of tool (primary and secondary)
and for the hunt.

## Rationale

The help is reference rather than a prompt, and is read as one.

## Acceptance criteria

1. The help shows the sections Reading the map, Walk mode, The primary tools,
   The secondary tools and The hunt.
