## Statement

The help **shall** describe every walk-mode tool separately, in full sentences.

## Rationale

Each tool behaves differently, and a list of keys does not say how.

## Acceptance criteria

1. Every tool of the tool row has a row of its own in the help with at least one
   full sentence.
