## Statement

The dart launcher **shall** have a scope, an air cylinder and a visible dart
that rides up after each shot.

## Rationale

All tools are built to the same standard of detail.

## Acceptance criteria

1. The launcher shows a scope, an air cylinder and a loaded dart.
2. The loaded dart disappears when fired and reappears before the gesture ends.
