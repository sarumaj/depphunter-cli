## Statement

`R` **shall** open a wheel showing every tool at once, with the hunt's tools
down the right half, the carried tools down the left half and an empty left hand
at the bottom of the left half.

## Rationale

The wheel is laid out the way the walker is.

## Acceptance criteria

1. The wheel has a wedge per tool and one for the empty hand, each exactly once.
2. The right half holds the primary tools and the left half the carried ones and
   the empty hand.
