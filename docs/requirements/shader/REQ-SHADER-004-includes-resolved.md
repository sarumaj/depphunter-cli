## Statement

The shader plugin **shall** resolve an include of GLSL or HLSL
(backslashes read as slashes) as the C/C++ plugin resolves a project header
(REQ-CPP-004: the includer's directory for the quoted form, a compilation
database's include paths, `include/`, `src/` and the root, then the file
whose path ends in the include), then relative to one of the includer's
parent directories, then either ignoring case. A virtual path **shall**
resolve as Unreal maps it: `/Engine/x` to `Engine/Shaders/x`,
`/Plugin/Name/x` to `Name/Shaders/x` and `/Project/x` to `Shaders/x`,
each where the repository has a file so ending; an unresolved `/Engine/`
or `/Plugin/Name/` path **shall** resolve to the "Unreal Engine shaders"
standard-library island (`unreal-engine`) as `Engine` or `Name`, and
another path starting with `/` (a GL_ARB named string) to the file at the
root or whose path ends in it. Any other include **shall** be dropped.

## Rationale

A shader includes only shader code: what the project does not have is
generated by the build or handed to the compiler by the engine. HLSL is
mostly written on Windows, where case does not matter.

## Acceptance criteria

1. `shaders/glsl/pbr.frag` links `common/lighting.glsl` beside it,
   `lib/noise.glsl` to `shaders/lib/noise.glsl`, `<brdf.glsl>` to
   `include/brdf.glsl` and `/shared/colors.glsl` to `shared/colors.glsl`;
   `generated/defines.glsl` is dropped.
2. `Utils.glsl` from `shaders/glsl/post/blur.comp` links to
   `shaders/glsl/utils.glsl`, and `samplers.hlsli` from
   `d3d/hlsl/Common.hlsli` to `d3d/include/Samplers.hlsli`.
3. In `Glow.usf`, `/Plugin/MyFX/Private/GlowCommon.ush` links to
   `Plugins/MyFX/Shaders/Private/GlowCommon.ush`, `/Engine/Private/Common.ush`
   resolves to `unreal-engine` `Engine`, `/Plugin/Niagara/...` to
   `unreal-engine` `Niagara`, and `/Project/Missing.ush` is dropped.
